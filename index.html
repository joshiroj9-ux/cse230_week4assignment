A hand-built image slider with smooth sliding, endless looping and touch-friendly controls.

About This Project

This slider uses HTML for structure, CSS for layout and sliding motion, and JavaScript for the controls and the infinite loop. It supports arrows, clickable dots, keyboard keys, swipe and drag, and optional autoplay.
